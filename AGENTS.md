# Agent instructions

## Spelling

Use American English in everything you write: comments, UI and status
strings, test names, identifiers, docs, commit messages and PR text. Write
`color`, `center`/`centered`, `behavior`, `gray`, `neighbor`, `normalize`,
`canceled`/`canceling`, `labeled`, `analyze`, and so on.

Issues are often written with British spellings. Don't copy that wording
into code; translate it to American as you go.

Keep external names as they are: the Web Audio API's `AnalyserNode` and
`createAnalyser` (and `analyser` variables holding one), the HTML attribute
`aria-labelledby`, and the GitHub Actions `cancelled()` function.
